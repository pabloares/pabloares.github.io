Poisson distribution and regression

What technique shall we use to model the counting of variables? Recall the Poisson probability distribution: it is a discrete distribution, with a single parameter \(\lambda\), given by the following expression: \[P(X = k) = \frac{e^{-\lambda}\lambda^k}{k!}.\] The parameter \(\lambda\) is understood as a rate: number of accidents per day, number of people admitted into emergency room per hour, etc. It can be scaled, in the sense that if \(\lambda\) corresponds to, say, defects in a meter of a wire, in two meters we have \(2\lambda\), and in half a meter we will have \(0.5\lambda\). A characteristic of the Poisson distribution is that the mean and the variance are both equal to \(\lambda\).

Here are the graphs of the Poisson distribution for different values of \(\lambda\). Observe how the probabilities decrease as \(k\) increases.

x <- 0:10
y <- dpois(x, lambda = 1)
z <- dpois(x, lambda = 2)
w <- dpois(x, lambda = 4)
plot(x, y, col="red", pch=16, type="o", xlab = "", ylab = "Probabilities",
     main = "Poisson distribution for different values of the parameter")
points(x, z, col="blue", pch=16, type="o")
points(x, w, col="darkgreen", pch=16, type = "o")
legend(x = 0, y = NULL, "Poisson distribution")
legend("topright",legend=c(1, 2, 4), col=c("red", "blue", "darkgreen"),
       text.col = c("red", "blue", "darkgreen"), ncol=1, lty=1, pch=16, cex=0.8)

Due to the scalability property of this distribution, it is good to model count variables: how many times certain events take place. “The Poisson regression assume that the response variable has a Poisson distribution, and assumes the log of its expected value can be modeled by a linear combination of unknowns parameters” (Wikipedia). Mathematically \[\ln(E[Y|x]) = \alpha + \beta\,x\] Thus the model gives a linear expression for the log of the conditional expected values. Some of the problems in the use of Poisson regressino occur when, for example, the observed variance is greater than the mean (overdispersion) or excesss zeroes.

Example 1

Let us work an example taken from reference 1. this link. The data has the number of awards earned by students in high school, along with their scores in the final math examination, and the program in which the students are enrolled: “General”, “Academic” and “Vocational”, encoded by numbers 1, 2 and 3 respectively. We start by reading the data and looking at the names of the variables.

poisson.sim <- read.csv("poisson-simulated-1.csv")
colnames(poisson.sim)

Let us convert variable program to a factor. And make barplots of the three categories.

poisson.sim$prog <- factor(poisson.sim$prog, levels = 1:3,

And now let us look at the barplots of the awards by categories.

You can see the means and variances by programs are similar, so we have a good candidate for a Poisson regression.

The coefficient for math is 0.07, which means that an increase of one unit in maths increases the log of the expected count increases by 0.07. And hence the count is multiplied by \(e^{0.07} = 1.07\). The indicator variable progAcademic compares between prog = “Academic” and prog = “General”

The R package sandwich can be used to estimate the parameters by what is known as robust standard errors. Here you have the code along with the p-values and the 95% confidence interval.

cov.m1 <- vcovHC(m1, type="HC0")
std.err <- sqrt(diag(cov.m1))
r.est <- cbind(Estimate= coef(m1), "Robust SE" = std.err,
"Pr(>|z|)" = 2 * pnorm(abs(coef(m1)/std.err), lower.tail=FALSE),
LL = coef(m1) - 1.96 * std.err,
UL = coef(m1) + 1.96 * std.err)

poisson.sim$phat <- predict(m1, type="response")
ggplot(poisson.sim, aes(x = math, y = phat, colour = prog)) +

The pseudo \({\boldsymbol R^2}\) is defined by \[R^2 = \frac{l(\hat{\beta_0})-l(\hat{\beta})}{l(\hat{\beta_0})} = 1 - \frac{-2l(\hat{\beta})}{-2l(\hat{\beta_0})}\] where \(l(\hat{\beta_0})\) is the log likelihood of the model when only the intercept is included. The pseudo \(R^2\) goes from 0 to 1 with 1 being a perfect fit. It can also be computed as \(1-\frac{\text{residual deviance}}{\text{null/total deviance}}\). In this case we have it is equal to

1 - m2$deviance / m2$null.deviance
## [1] 0.423676
